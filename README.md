# boulder

[![CI](https://github.com/bekapod/boulder/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/bekapod/boulder/actions/workflows/ci.yml)

A Game Boy game, written in C with GBDK-2020 for the original DMG hardware.

## Prerequisites

- [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) — the C compiler and
  toolchain. Tested with v4.5.0; install to `~/gbdk/` or set `GBDK_HOME`.
- `make` — comes with the Xcode command line tools, probably already on your machine.
- An emulator to run it. I'm using [SameBoy](https://sameboy.github.io/) atm
  and it has a debugger.
- [uv](https://docs.astral.sh/uv/) — only if you want to run the tests.
  `brew install uv`.

## Building

```sh
make
```

One of the outputs is `build/boulder.gb` which can be opened with an emulator.

```sh
make clean
```

Deletes everything generated by the build.

## Testing

```sh
make test
```

Builds the ROM if it needs to, then runs a pytest suite that boots it
headlessly in [PyBoy](https://github.com/Baekalfen/PyBoy) and asserts against WRAM.

## Running

Open `build/boulder.gb` in your emulator. The build also produces `build/boulder.sym`.
SameBoy picks it up automatically if it's in the same directory as the ROM,
and then the debugger shows actual label names instead of bare addresses.

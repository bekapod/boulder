# boulder

A Game Boy game, written in assembly for the original DMG hardware.

## Prerequisites

- [RGBDS](https://rgbds.gbdev.io/) — the assembler toolchain (rgbasm, rgblink,
rgbfix, rgbgfx). Tested with v1.0.3. `brew install rgbds` on a Mac.
- `make` — comes with the Xcode command line tools, probably already on your machine.
- An emulator to run it. I'm using [SameBoy](https://sameboy.github.io/) atm
and it has a debugger.

## Building

```sh
make
```

One of the outputs is `boulder.gb` which can be opened with an emulator.

```sh
make clean
```

Deletes everything generated by the build.

## Running

Open `boulder.gb` in your emulator. The build also produces `boulder.sym`.
SameBoy picks it up automatically if it's in the same directory as the ROM,
and then the debugger shows actual label names instead of bare addresses.
